# Importar no IV Studio

O Virtual Set não submete vídeos automaticamente ao MiniMax H3. Para usar o MP4 como referência, abra o IV Studio, crie ou abra a edição pretendida, importe `Sala-experimental-6x5.mp4` para o Media Bin e acrescente-o à timeline ou ao plano como referência, conforme o fluxo do projeto. Reveja enquadramento, duração e movimento antes de qualquer geração H3.

Este procedimento é manual e não modifica projetos ou filas por si só.
