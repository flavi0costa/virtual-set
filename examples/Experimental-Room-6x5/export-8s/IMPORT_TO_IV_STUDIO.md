# Import into IV Studio

Virtual Set does not submit footage to MiniMax H3 automatically. To use the MP4 as a reference, open the intended IV Studio edit, import `Experimental-Room-6x5.mp4` into the Media Bin, and add it to the timeline or shot as a reference using that project's workflow. Review the framing, duration, and camera movement before rendering with H3.

This is a manual workflow. It does not modify projects or queues by itself.
